# Release history

## 2.0.0 — 2026-10-28

This public release consolidates the latest development build (2.0.9) under the requested 2.0.0 version. The embedded version is `2.0.0+mc1.21.11`.

- Character combat potions: Wemmbu, Flame and Jaden assisted/automatic modes, permanent H-menu unlocks, temporary equipment and restoration of the original identity/inventory.
- Spoke, Lettuce and Ashswagg guard abilities with NULL, LAW and Mafia armies, replenishment and permanent character alliances.
- Standalone Far Lands at ten million blocks, multi-region progression, rotating navigation map, story echoes and the Golden City.
- Village farming interactions, the Mist, coordinate maps, 4CViT pearl cannons and the portable slime bucket.
- Expanded meme voice triggers, character interactions, menu presentation and 38 purple challenge objectives.
- Orbital and wither cannons default to twelve rings; `/uu orbital rings` and `/uu wither rings` query or set their separate world-wide counts (1–16).
- Full dimension-height bunker busters: 384 hidden blast nodes at Y=-64..319 in the Overworld. Native TNT resistance protects obsidian and similarly resistant blocks; liquids retain their resistance. Held shields prevent direct drill damage while preserving knockback.
- Phantoms, drowned and withers stay at or below feet Y=300, with lower caps in dimensions whose build height requires them.
- Jaden's continuous Riptide uses a twenty-tick cycle; fixed spin-pose misclassification, and retained falling-mace hits and water-bucket landings.
- Phantoms with both cannon supplies exhausted always select their mace and clear the rod.
- Optional user-supplied MP3/Vorbis battle music. The fifth combined successful orbital/drill use in one Wemmbu activation switches to the local war track. No battle songs are bundled.

Requires Minecraft Java 1.21.11, Java 21+, Fabric Loader 0.19.5+ and Fabric API 0.141.6+1.21.11 or a newer compatible 1.21.11 build. Update both multiplayer sides and remove the old JAR. Far Lands terrain affects newly generated standard Overworld chunks.
