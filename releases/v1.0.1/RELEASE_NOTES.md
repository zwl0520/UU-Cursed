UU Cursed brings Unstable SMP characters and memes into Minecraft through custom mob appearances, combat behaviors, items, voice clips, and advancements.

## What's new in 1.0.1

- Removed the bundled Wemmbu and Flame battle music and automatic proximity playback.
- Kept all five meme voice clips, character textures, combat behaviors, items, particles, and advancements.

## Featured gameplay

- Wemmbu phantoms wield maces, perform accelerating aerial dives, and can carry a single-use orbital strike rod.
- Jaden drowned wield Riptide tridents and maces, using them for aerial combat in rain and underwater combat.
- Parrot, Wemmbu, and Theo parrots have distinct appearances, voice behavior, and healing or explosive abilities.
- Character-inspired fish, axolotls, slimes, wolves, wardens, bosses, and other mobs, plus themed items and face-icon advancements.
- SargeLAW TNT minecarts, Spoke wither revival, Flame mobs with three totem saves, and a Wifies spyglass Easter egg.

## Requirements

- Minecraft Java Edition **1.21.11**
- **Java 21** or newer
- **Fabric Loader 0.19.5** or newer
- **Fabric API 0.141.6+1.21.11** or a newer build for Minecraft 1.21.11

## Installation

Place `UU_Cursed_v1.0.1_Fabric_1.21.11.jar` and Fabric API in your Minecraft `mods` folder. Replace the previous UU Cursed JAR rather than keeping both versions installed.

This is a Fabric mod with bundled textures and sounds; a separate resource pack, ETF, or EMF is not required.

The release includes a SHA-256 checksum file for the JAR. This is an unofficial fan project and does not imply endorsement by the featured creators.
