## UU Cursed 2.0.0 — Minecraft Java 1.21.11 / Fabric

Created by **筑梦-星空 (Bilibili) / DreaminStars (YouTube)**.

This is the full new public release, including all gameplay and fixes from development builds through 2.0.9. The JAR's embedded version is **2.0.0+mc1.21.11**.

### New adventures and abilities

- Wemmbu, Flame and Jaden combat potions: assisted combat, automatic control, borrowed equipment and permanent unlocks in the H menu.
- Spoke, Lettuce and Ashswagg guard abilities: NULL, LAW and Mafia armies and permanent alliances with matching character mobs.
- Standalone Far Lands starting at ten million blocks, distinct terrain regions, a rotating map, story echoes and the Golden City.
- The Mist, village interactions, coordinate maps, 4CViT pearl cannons and the portable slime bucket.
- Expanded voices, character interactions, title-screen presentation and 38 purple challenges.

### Latest combat refinements

- Orbital and wither cannons default to twelve concentric rings. Change them independently with `/uu orbital rings <1–16>` and `/uu wither rings <1–16>`.
- Bunker busters cover the full dimension build height (Overworld Y=-64..319), use normal TNT block/fluid resistance, and retain increased damage plus held-shield damage protection and knockback.
- Phantoms, drowned and withers have a maximum feet altitude of Y=300, adjusted down where a dimension's build height requires it.
- Jaden's continuous Riptide uses approximately one activation per second at normal tick rate, retaining real mace hits and safe water landings.
- Phantoms always use their mace after both cannon ammunition supplies run out, while respecting already-fired payload safety intervals.
- Optional local MP3/Ogg Vorbis battle music supports both cannon types; the fifth combined successful use in one Wemmbu activation switches to the local war track. No battle songs are bundled.

### Installation

1. Minecraft Java **1.21.11**, **Java 21+**, **Fabric Loader 0.19.5+**.
2. Install **Fabric API 0.141.6+1.21.11** or a newer Fabric API build for 1.21.11.
3. Put the mod JAR and Fabric API in the instance's `mods` folder; remove the previous UU Cursed JAR.
4. Multiplayer requires both client and server to update.

Textures, models and sounds are included. No separate resource pack, ETF, EMF or Unstable Generation is required. New Far Lands terrain applies to unexplored standard Overworld chunks.

### Controls

**H:** ability menu · **Shift:** pause automatic control · **G:** resume · **M:** Far Lands map while inside the region · **Milk:** clear the active potion.
