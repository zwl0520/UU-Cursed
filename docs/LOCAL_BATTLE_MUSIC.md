# 本地角色战斗音乐

启动游戏后，将自备的 MP3 或 Ogg Vorbis 文件放到当前游戏实例的 `config/uu_cursed/music/`：

| 文件名 | 用途 |
| --- | --- |
| `wemmbu.mp3` 或 `wemmbu.ogg` | Wemmbu I / II 战斗音乐 |
| `flame.mp3` 或 `flame.ogg` | Flame I / II 战斗音乐 |
| `war.mp3` 或 `war.ogg` | 本次启用 Wemmbu 能力后，轨道炮与钻地炮合计成功消耗满 5 发时切换（包括第五发） |

同名两种格式同时存在时，优先 MP3；MP3 损坏则尝试 Ogg。Ogg 使用 Vorbis 编码，不支持只改扩展名，也不支持 Ogg 容器中的 Opus 编码。

永久解锁后，通过 H 开启的 I / II 同样支持。轨道炮与钻地炮由服务器合并统计，手动、自动均计入；每次成功消耗一发计一次，发射失败不计入，不按TNT数量、圈数或爆炸点计数。三发轨道炮加两发钻地炮，或连续五发钻地炮，都会在第五发切换到war。
每次重新喝药、启用/切换能力、死亡或退出游戏，计数重新开始。脱战不会清除本次启用的计数。
没有 war 文件时继续播放 wemmbu；没有某角色文件时不播放该角色音乐，不影响能力。

攻击、受袭、控制器锁定战斗目标或发射任一种炮后开始循环播放，脱战约 10 秒后用约 1 秒淡出。解除能力、死亡、退出立即停止，切换角色时换曲。
仅使用者本机听到，歌曲不向服务器或其他玩家传输。使用游戏的“音乐”和“主音量”滑块控制；单人暂停时同步暂停。
歌曲在下次开播时从文件读取，无需资源重载；正在播放的文件建议等停播再替换。损坏文件会跳过，更换后重进世界再试。
两种格式均采用流式读取，不会把整首歌曲载入内存。模组不附带歌曲。

MP3 支持使用未修改的 JLayer 1.0.1（LGPL-2.0-or-later）。依赖库、完整对应源码和许可见包内 `META-INF/jars/`、`META-INF/licenses/jlayer/`，库允许依照该许可替换、调试和修改。
