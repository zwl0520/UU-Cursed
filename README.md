# UU Cursed

A Minecraft Java 1.21.11 Fabric fan mod bringing Unstable SMP characters and memes into the game through custom mobs, combat behaviors, items, voice clips, and advancements.

[Download the latest release](https://github.com/zwl0520/UU-Cursed/releases/latest)

## Highlights

- Wemmbu phantoms with mace dives, firework trails, and single-use orbital strike rods.
- Jaden drowned with Riptide tridents, maces, and aerial or underwater combat.
- Parrot, Wemmbu, and Theo parrots with distinct appearances and healing or explosive abilities.
- Spoke fish and withers, SargeLAW TNT minecarts, Flame mobs with three totem saves, and a Wifies spyglass Easter egg.
- Character-inspired axolotls, slimes, wolves, wardens, other mobs, themed items, and face-icon advancements.

## Installation

1. Install Minecraft Java **1.21.11**, Java **21** or newer, and Fabric Loader **0.19.5** or newer.
2. Install **Fabric API 0.141.6+1.21.11** or a newer Fabric API build for Minecraft 1.21.11.
3. Download `UU_Cursed_v1.0.1_Fabric_1.21.11.jar` from [Releases](https://github.com/zwl0520/UU-Cursed/releases/latest) and put it in your Minecraft `mods` folder. Replace the previous UU Cursed JAR when updating.

Textures and sounds are bundled in the mod. A separate resource pack, ETF, or EMF is not required.
