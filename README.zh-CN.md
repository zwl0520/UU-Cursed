## 第一次玩，推荐怎么开始

1. **先在普通世界看人物生物。** 创造模式可用原版对应的刷怪蛋生成幻翼、溺尸、烈焰人、鹦鹉、史莱姆等；许多刷怪蛋也换上了人物外观。
2. **体验辅助模式。** 用粗制药水和烟花火箭酿造 Wemmbu I，自己飞行、瞄准，感受换胸甲与重锤命中的辅助。
3. **体验自动操控。** 再用鞘翅把 I 升为 II，在开阔场地观察自动起飞、俯冲、补给和群体炮击。按 **Shift** 可暂时拿回操作权。
4. **解锁 H 能力菜单。** 用粗制药水和重锤酿造 Wemmbu III；使用后在 **H** 菜单里自行开启或关闭能力。
5. **找一只 4CViT 史莱姆。** 给它地图，或在附近发送目的地坐标，试一次珍珠炮旅行；也可以把它装桶带走。
6. **准备边境远征。** 向村庄制图匠购买边境地图，带上风弹、末影珍珠和搭路方块，再去寻找黄金城。

轨道炮、钻地炮和生物的爆炸攻击会影响周围环境，适合在远离重要建筑的区域体验。

## 主要战斗生物

### Wemmbu 幻翼

幻翼有 Wemmbu 的扁笑脸和黄色头冠，翅膀为**灰色鞘翅色或紫色渐变**两种外观。武器位于左右翼附近；它拥有重锤、轨道炮和钻地弹三种攻击方式。

- **重锤俯冲：** 从远处高空接近，以加速下凹曲线俯冲，身后有烟花尾迹；转弯时减速。下落距离会影响锤击伤害，命中伴随重锤粒子和击退。
- **近身反击：** 对飞到身边的目标也能使用重锤。
- **有限军火：** 每只携带重锤、十次轨道炮和十次钻地弹，并有十次隐藏图腾复活。两种炮都耗尽后固定使用重锤。
- **炮击间隔：** 释放轨道炮或钻地弹后进入十秒攻击冷却，并会避开尚未结束的炮击。
- **目标与关系：** 会攻击玩家、Jaden 溺尸、Spoke 凋灵和 Flame 两种形态等目标。与 Flame 交战时，一方在这场对决中爆掉三个图腾后停战。
- **Eggchan 尾链：** 会拾取附近的鸡蛋和雪球，挂在尾部形成一串。
- **生成与生存：** 夜间生成不再要求玩家失眠；不会因阳光燃烧，但仍受正常生成条件、难度和自然消失规则影响。
- **掉落：** 玩家击杀时有 3% 概率获得重锤；仍保有未使用轨道炮能力的幻翼另有 5% 概率掉落轨道炮鱼竿。

玩家吃下 ManePear 苹果，可以直接清除附近 **100 格**内的幻翼。击杀幻翼可获得 **the “stable” smp** 挑战。

### Jaden_MAN 溺尸

溺尸统一使用 Jaden 形象，双持**激流三叉戟与重锤**。

- 雨中连续使用激流获取高度、修正位置，再下落重锤攻击；激流之间仍受重力影响。
- 水中也能用激流接近目标，配合近战或重锤，不要求一定下雨。
- 未锁定目标时以地面和水中活动为主，满足巡查条件时才短暂升空；锁敌后进入持续战斗。
- 会与幻翼、Spoke 凋灵等角色生物交战，也会攻击乐魂和雪傀儡等目标。
- 不会因阳光燃烧。击杀携带三叉戟的 Jaden 溺尸可获得 **The great sea**。

幻翼、溺尸和凋灵的飞行脚底高度均限制在 **Y=300** 以内；其他维度还会受实际建筑高度限制。

### FlameFrags 烈焰人与恶魂

**烈焰人**保留原版漂浮头部与旋转烈焰棒的轮廓，使用 Flame 的人物纹理。

- 烈焰弹伤害提高到原先的三倍。
- 玩家靠近时，旋转的棒子会通过聚合动画组成火剑，进入近战。
- 图腾被打爆后，可用鱼竿召来三十只穿狼铠的狼；这些狼带有力量、迅捷和抗火效果，保护烈焰人。

**恶魂**使用 Flame 的头部外观，发射的攻击变成沿直线前进、不受重力影响的 TNT 矿车。

两种形态都有**十次图腾复活**，还会寻找并销毁地上掉落的重锤和鞘翅；背包中的物品不受这项行为影响。耗尽其图腾并最终击杀，可获得 **the immortal demon**。

### SpokeIsHere 凋灵

三个头和发射的凋零之首都使用 Spoke 的脸，持有带附魔光效的不死图腾。

- 图腾触发后恢复至半血。
- 出现十秒后开始使用同心圆凋零炮，正常每十秒一轮；附魔图腾被打爆后改为每五秒一轮。
- 默认每轮十二圈，圈数可以通过命令调整。
- 召集全黑形象、随机名字、穿附魔下界合金甲的 **NULL 士兵**，通过浮空地狱传送门出场。
- NULL 士兵协助攻击凋灵的目标，必要时主要向上搭方块；凋灵不会主动把自己的 NULL 当敌人。
- 凋灵的附魔图腾爆掉后，其 NULL 士兵会真正死亡清除。

## 角色药水与永久能力

### I、II、III 分别是什么？

| 类型 | 持续时间 | 玩家如何操作 |
| --- | --- | --- |
| Wemmbu / Flame / Jaden **I** | 五分钟 | 保留玩家移动和瞄准，辅助完成该角色的战斗动作 |
| Wemmbu / Flame / Jaden **II** | 三分钟 | 自动操控移动、选敌和战斗，可手动暂停 |
| Wemmbu / Flame / Jaden **III** | 永久解锁 | 只解锁该角色 H 菜单中的能力，不立即变身、换装备或播放转场 |
| Spoke / Lettuce / Ash **限时药水** | 五分钟 | 获得对应护卫与装备；这三类不分 I、II |
| Spoke / Lettuce / Ash **永久药水** | 永久解锁 | 在 H 菜单里自行开启、关闭对应护卫能力 |

同一时间只启用一个角色形态。**永久解锁会随玩家保存，死亡后保留；关闭能力不等于删除解锁。**

实际启用角色能力时，会切换为角色外观和名字，显示角色转场，并借用相应装备与有限补给。原来被替换的背包物品、盔甲、副手以及身份在效果结束或关闭后恢复。所有正在启用的角色能力均提供**力量 II**；只解锁而未启用时不会获得战斗增益。

### Wemmbu：鞘翅与重锤

- **装备方向：** 下界合金甲、鞘翅、Gambit 与 Crucible 两把重锤、下界合金剑、四组烟花、金苹果、十个图腾，以及各十次轨道炮和钻地炮。
- **重锤核心附魔：** Gambit 使用密度 V、风爆 II；Crucible 使用破甲 IV。装备来自当前模组的角色套装。
- **I 辅助：** 玩家瞄准并进行鞘翅俯冲时，辅助切胸甲、切重锤和命中；不要求玩家事先拿着重锤，完成后回到锤击前选择的物品格。
- **II 自动：** 在 128 格范围内选敌，人物生物和军队士兵优先；包括末影龙等魔改生物。锁定后进行起飞、烟花加速、俯冲和重锤攻击，狭窄地形可转近战，血量不足时尝试脱离并回血。
- **对多炮击：** 自动模式面对至少四个地面敌人时可以选择炮击；开阔群体使用轨道炮，被遮挡的群体使用钻地炮。I 模式也能手动使用借用鱼竿。
- **有限补给：** 切换 I / II 或保存重进不会把已消耗的同一套炮弹重置成满额。

### Flame：剑斗与 TNT 矿车

- 使用 **The Flame** 下界合金剑、**Inferno** 下界合金斧、**Incendiary** 火弓，以及纹饰下界合金甲。
- 配有铁轨、TNT 矿车、箭、末影珍珠、金苹果和十个图腾。
- **I 的矿车辅助操作：** 手持铁轨或 TNT 矿车，瞄准约 5—15 格外的目标并按住使用；辅助放置真实铁轨和矿车，用火弓点燃，随后恢复原物品格。
- **II 自动战斗：** 近身剑斧战斗，中距离布置矿车并拉弓引爆，面对聚集敌人优先考虑爆炸范围；低血量时使用珍珠拉开距离并吃苹果。
- 自己这套临时装备放出的攻击矿车对使用者有保护；放置仍要求合适地面、可达距离、弹药和射击空间。

### Jaden：连续激流接下落锤

- 使用钻石甲、**激流 III / 穿刺 V 三叉戟**、**密度 V / 风爆 III 重锤**，配有剑、水桶、珍珠、金苹果和十个图腾。
- **I 辅助：** 玩家负责移动与瞄准，下落接近目标时辅助重锤；错过锤击、临近地面时尝试落地水。
- **II 自动：** 在水中或雨中连续蓄力、释放激流，目标节奏约每秒一次，调整高度和水平位置；到达攻击位置后转入下落锤，而非不断用激流打断下砸。
- 干燥地面会尝试利用水桶；下界无法正常放水，转为近战。原版激流的湿润条件仍然适用，下雪不等于下雨。

自动操控会受地形、目标移动和原版物理影响。想恢复操作，按 **Shift** 暂停；想结束整套效果，在 H 菜单选择回到自己，或暂停后喝牛奶。

## 三种军队与角色盟友

### 玩家召唤的护卫

## 轨道炮、钻地炮与鱼竿绑定

### 轨道炮

用鱼竿形式的道具指定目标，召来多圈同心圆 TNT 炮击。默认 **十二圈**，主要覆盖地表与开阔群体。

### 钻地炮

在目标位置沿当前维度的完整建筑高度形成一列同时爆炸的隐藏爆炸节点。主世界覆盖 **Y=-64 至 Y=319**，不会显示一长串 TNT 矿车实体。

它采用正常 TNT 的方块抗爆逻辑：**黑曜石等高抗爆方块不会因为钻地炮而被强行删除，流体也保留原版抗爆保护。** 手持盾牌可防住该炮的直接伤害，但仍会受到击飞。

### 如何取得和使用？

- 创造模式可在“战斗”栏找到两种炮，也可搜索道具名称。
- Wemmbu I / II 的临时套装各提供十次两类炮击。
- 边境深度约 800 格的轨道炮断层区域存在红石机器外观。把**普通鱼竿的浮漂甩到机器指定的金质压力板上**，鱼竿会等概率变成一次性轨道炮或钻地炮。
- 每次成功使用消耗一支，包括创造模式。玩家使用没有幻翼的十秒攻击冷却；未成功发射不消耗弹药。
- 炮机与珍珠炮的红石结构用于外观和互动定位，实际炮击、计时和传送由模组实现，不要求电路以纯原版红石方式工作。

管理员可以使用 `/uu orbital rings <1—16>` 或 `/uu wither rings <1—16>` 修改各自圈数，设置保存在世界中。圈数越多，生成的爆炸和实体越多。

## 村庄、迷雾与珍珠炮

### 村庄生活与两类地图

Lomedy 农民会不断向村庄外开垦并种植麦田，Spongs 苦力怕则会破坏这些麦子。

制图匠增加两类坐标地图交易：

- **迷雾地图：** 指向主世界迷雾中心 `X=2,000,000，Z=-2,000,000`。迷雾范围约为 **2000×2000 格**，带有蓝色调的雾效果。
- **边境之地地图：** 指向正负 X、Z 四条坐标轴上的边境入口，目的地位于正常世界一侧，距边境约一百格。

这些物品主要提供目的地坐标；进入边境后按 M 打开的导航地图，是另一套独立界面。

### 让 4CViT 帮你建珍珠炮

可以通过以下方式交代目的地：

1. 手持普通地图、迷雾地图或边境地图，右键 **4CViT 史莱姆**。
2. 手持写有坐标的书，右键 4CViT。
3. 在 4CViT 附近放置写有坐标的告示牌。
4. 距离 4CViT 不超过十格，在聊天栏直接发送坐标，例如 `X: 1000 Z: -2000`。

坐标可写成 `1000 -2000`，也可用常见的 `X Y Z` 三坐标形式；目的地取 X、Z，落脚高度由安全地面搜索决定。普通地图使用其中心坐标。

史莱姆会在附近寻找空间建造炮机；地面放不下时，会尝试寻找更高的空中位置。建好后找到标明投掷点的告示牌，站到干燥入口，**朝上投出末影珍珠**。

珍珠会先停在发射位置，旁边的 TNT 随后爆炸将其推出。大约十秒后，模组把玩家传送到目标附近可站立的安全位置，并显示珍珠落地粒子。目标区块加载较慢时可能需要更久；找不到安全落点时会取消并退还珍珠。

对 4CViT 使用桶可以将它随身携带，需要时释放。Wifies 和 PlanetLord 史莱姆不具备这项工程师能力。

### 旅行规则

- **深入五百格后，烟花火箭不再给鞘翅提供正常推进。** 风弹和末影珍珠仍能使用。
- 分形与纯虚空交界附近，每条坐标轴路线上各有一个只长一棵树的小平台。
- 五种剧情回声布置在坐标轴路线附近，沿轴前进更容易发现。

### M 导航地图

只有进入边境之地后，才能使用对应快捷键打开地图。地图以**玩家面向的方向作为上方**，随朝向旋转，显示当前位置、分区进度、后续区域以及黄金城等结构位置。

边境不是普通世界出生点附近的群系。旧存档中已经生成过的远方区块不会被自动重写；请到尚未生成的位置体验新地形。

### 五类剧情回声

回声使用人物皮肤与代表性装备，循环演出，每段约半分钟以上。玩家可以旁观，不能像普通生物那样攻击或推动回声人物；演出不会为人物额外铺一条实体道路。

2. **雪地中的饥饿：** 一名无装备玩家在尖峰雪地行走，最终饿死。
3. **尖峰区域的交战：** Flame、Wemmbu 与 Jaden、WyLL、Sharpness 对战。
4. **悬浮岛穿行：** Wemmbu、Eggchan、Jaden 使用风弹与珍珠跨越岛屿。
5. **通往黄金城的搭路：** Wemmbu 与 Eggchan 在分形到虚空区域轮流向前搭路。

## 自备战斗音乐

模组**不附带战斗歌曲**。启动游戏后，可把自己准备的 MP3 或 Ogg Vorbis 文件放入当前实例的 `config/uu_cursed/music/`：

| 文件名 | 用途 |
| --- | --- |
| `wemmbu.mp3` 或 `wemmbu.ogg` | Wemmbu I / II 的本地战斗音乐 |
| `flame.mp3` 或 `flame.ogg` | Flame I / II 的本地战斗音乐 |
| `war.mp3` 或 `war.ogg` | 本次 Wemmbu 能力启用期间，两类炮累计成功使用到第五发时切换 |

轨道炮与钻地炮合并计数，手动和自动发射都计入，按实际成功消耗的鱼竿次数计算；三发轨道炮加两发钻地炮也会在第五发切换。单次攻击的 TNT 数量和圈数不会额外增加计数。

战斗时播放，脱战约十秒后淡出；解除能力、死亡或退出世界停止。只有使用者本机能听到，不向服务器或其他玩家传输歌曲。缺少某个文件时，相应能力仍正常使用；缺少 war 则继续使用 wemmbu 曲目。

同名两种格式都在时优先 MP3。Ogg 必须是 **Vorbis 编码**，只改扩展名无效。音量由游戏“音乐”和“主音量”控制。

## 常见问题

**这是资源包还是模组？** 这是 Fabric 模组。除了外观，还改动生物 AI、战斗、药水、军队、物品交互和世界生成。

**能用 Forge、基岩版或网易客户端直接打开这个 JAR 吗？** 本页下载的是 Java 1.21.11 / Fabric 文件，其他平台需要各自适配包。

**喝了 III 为什么没变身？** III 只永久解锁。按 H 进入该角色页面，再开启 I 或 II；护卫角色同样需要在菜单启用。

**不想继续被自动操控怎么办？** Shift 暂停操作接管，G 恢复。H 中回到自己会结束角色形态，喝牛奶也可以清除当前效果。

**临时装备会一直留在背包里吗？** 能力装备和补给是借用套装。结束后恢复原来被替换的装备和身份，永久解锁与临时道具是两回事。

**为什么找不到黄金城？** 城市只在四条坐标轴上，中心坐标见前表；横向偏离路线、尚未走完虚空段或走到旧生成区块，都可能看不到目标。

**为什么边境用烟花飞不动？** 深入五百格后的区域有意禁用烟花推进，改用风弹、珍珠和搭路。

**为什么珍珠炮没有立刻传送？** 需要在指定入口向上投珍珠，等待约十秒，并等待目标区块完成加载；没有安全落点时会取消。

**为什么军队剩十个人没有补兵？** 触发条件是少于十个，不是小于等于十个。

**多人联机为什么也要装客户端？** 人物渲染、语音、转场和能力菜单依赖客户端；AI、伤害、物品和世界逻辑依赖服务器，因此双方都要安装一致版本。

**有没有幽灵维度或强制 UG 前置？** 幽灵维度已撤销；当前边境生成独立实现，不需要 Unstable Generation 前置。
